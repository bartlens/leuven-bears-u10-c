# Leuven Bears U10 C 🐻🏀

Vite + React + TypeScript + Tailwind site for the Leuven Bears youth team **U10 C** (seizoen **2026 - 2027**).

## Scripts

- `npm run dev` — local preview
- `npm run build` — production build
- `npm run preview` — preview build

## Data

- Roster, staff, trainings: `src/data/players.ts`, `src/data/team.ts`, `src/data/trainings.ts`
- Match calendar: `src/data/matches.ts`
